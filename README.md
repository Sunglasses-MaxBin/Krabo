# Krabo - 手表空气手枪

Krabo 是一个专为 Android 5.0 及以上版本的老旧安卓手表设计的极简空气手枪应用。灵感来源于火爆的"螃蟹acto"梗，旨在填补低配安卓设备在此类互动玩法上的空白。

## 核心特点

- **专为老旧设备打造**：最低支持 Android 5.0 (API 21)，完美适配低性能、低内存的安卓手表。
- **极简纯粹的设计**：界面仅有纯黑底色与白色文字，无任何花哨冗余的元素，保证在小屏手表上的清晰度。
- **双触发机制**：既支持点击屏幕直接触发音效，也支持向前挥舞拳头（重力感应）触发音效。
- **双角色无缝切换**：通过界面两侧的左右箭头，一键切换角色，每个角色拥有独立的专属贴图与音效。
- **老设备深度优化**：
  - 彻底解决老系统 SoundPool 音量调节卡死的底层 Bug（改用 MediaPlayer 实时读取系统音量）。
  - 内置 400ms 防 ANR（应用无响应）时间锁机制，防止传感器高频回调拖死低性能手表。

## 如何构建

### 环境要求
- Android Studio (建议使用较新版本)
- Java 8 或更高版本
- Android SDK (最低 API 21)

### 构建步骤

1. 克隆仓库到本地（注意把链接换成你自己的）
   ```bash
   git clone https://github.com/你的用户名/Krabo.git
```

2. 使用 Android Studio 打开项目，等待 Gradle 同步完成。
3. 准备应用所需的资源文件（见下方说明）。
4. 连接你的安卓手表，或启动一个 API 21 及以上的模拟器。
5. 点击 Android Studio 顶部的运行按钮，将应用安装到手表上。

资源文件配置（必备）

由于版权原因，本仓库不包含原始的音频和图片资源。如果直接编译运行而不放入对应文件，应用在触发时会闪退或无声。

请自行在以下目录放入文件：

· 音效文件：放入 app/src/main/res/raw/ 文件夹，命名为：
  · role1.wav
  · role2.wav
· 角色贴图：放入 app/src/main/res/drawable/ 文件夹，命名为：
  · role1.png
  · role2.png
